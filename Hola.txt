Descripción:
Propósito:

Ampliar la práctica anterior, para proteger ficheros utilizando un algoritmo de resumen (Hash, MAC, HMac). La práctica permite calcular un resumen del contenido del fichero con distintos algoritmos, que puede elegir el usuario mediante el parámetro correspondiente. Se añade una cabecera al fichero de salida, en la que se almacena la información necesaria para poder reconocer el fichero y comprobar su integridad. Es decir, la aplicación aplica una especie de vacuna al fichero. Para evitar la falsificación del resumen, se utilizará un valor secreto que debe suministrar el usuario; dicho valor secreto se usará como SECRETO COMPARTIDO o como passwd para generar una clave secreta, según el algoritmo elegido.
Implementación:
J2SDK v1.4 o superior.
Clases a utilizar (de la librería J2SDK):
1. Funciones Hash (Digests):

MessageDigest: Esta clase representa al algoritmo hash, y se encarga de realizar el trabajo. Permite seleccionar el algoritmo hash a utilizar. Se inicia de la siguiente forma:
MessageDigest md = MessageDigest.getInstance(algorithm);

md.update(secret);

DigestInputStream: Nos permitirán calcular el resumen de los datos obtenidos de un flujo de entrada. Opera con un MessageDigest previamente configurado. La forma de iniciarlo es:
DigestInputStream dis = new DigestInputStream(InputStreamYaIniciado,md);
